# public.clients

## Description

OAuth 2.1 / OIDC クライアントテーブル。  
各サービスは Client Credentials または Authorization Code フローでトークンを取得し、  
ユーザーの所属グループ情報等を取得できる。  


## Labels

`OAuth2/OIDC`
